## 第 2 件事 · 加 include guard（30 分钟）

你说查过了但还是不会加。**那我直接给你样子，不让你再查了** ——
这东西是死记的格式，不是需要你悟的东西。

include guard 长这样，**它必须包住头文件里的全部内容**：

```c
#ifndef <一个独一无二的名字>
#define <同一个名字>

    你头文件里所有的内容，都写在这里

#endif
```

说明：

- 那个名字随便取，但要**独一无二**。行业惯例是拿文件名来改：
  `math_utils.h` → 名字取 `MATH_UTILS_H`
- 三行都是**预处理指令**，必须写在行首（前面不能有空格）
- `#ifndef` = "if not defined"，`#define` = 定义

**现在你来**：把这三行加到你的 `math_utils.h` 里，让第一行是 `#ifndef`，
最后一行是 `#endif`，中间包住你那两行函数声明。

改完编译一次，确认还能跑通（这时候程序应该**链接失败**，因为第 3 件事还没做 —— 那是正常的）。

### 🤔 然后回答这个问题（这个比语法重要）

我往头文件里加了两样不同的东西，你判断一下**哪个必须靠 include guard 保护**：

**东西 A**：`int add(int a, int b);`  ← 函数声明

**东西 B**：`int g_count = 0;`  ← 变量定义

**我实测过**：A 重复两边不会报错；B 重复两边会报错（`C2374` 重定义）。

**为什么？** 提示：想想"声明"和"定义"的区别 ——
声明只是**告诉**编译器"有这么个东西"，定义是**真的把它造出来**。
"告诉"两遍有事吗？"造"两遍呢？
