### 闭卷检验题（让他不看任何东西，白纸写出来）

1. `As[ty][tx] = A[ ??? ]`、`Bs[ty][tx] = B[ ??? ]`，两个方括号里各填什么？
   为什么 A 那行用 `tx` 做片内偏移、B 那行用 `ty`？
2. 内层循环为什么是 `As[ty][k] * Bs[k][tx]`？换成 `As[k][ty] * Bs[k][tx]` 错在哪？
3. 片 `t=3`、线程 `tx=7` 时，`As[ty][7]` 里装的是 A 的第几个全局 k？
4. `block(32,32)` 下，`As` / `Bs` 用 `[32][32]` 够不够？要不要 padding？

**参考答案（判卷用）**

1. `As[ty][tx] = A[row * N + (t*32 + tx)]`；`Bs[ty][tx] = B[(t*32 + ty) * N + col]`。
   因为 A 的 k 是**列**（`A[row][k]`），B 的 k 是**行**（`B[k][col]`）；
   而一个 warp 内 `ty` 固定、`tx = 0..31`，所以片内偏移必须交给 `tx` 才能合并访存。
2. 因为 `As` 的第 2 维是 k（存的时候 `t*32+tx` 进了列位），`Bs` 的第 1 维是 k
   （存的时候 `t*32+ty` 进了行位）。`As[k][ty]` 是把两个维度对调了，取到的不是同一个数。
3. `3*32 + 7 = 103`。
4. **不需要 padding，`[32][32]` 就够。**
   - `As[ty][k]`：warp 内 `ty` 固定、`k` 是同一个循环变量 → 32 个线程**同地址 → 广播，免费**
   - `Bs[k][tx]`：地址 = `k*32 + tx`，`bank = (k*32+tx) % 32 = tx` → 32 个 bank 全不重

任何一题答错，**从 `N=4` 的小例子重来**，不要跳回 32×32。

### 已知的两个坑，讲的时候一定要点破

- ❌ **"一个线程管 32 个元素"** —— 错。`__shared__ float As[32][32]` 是 1024 个 float，
  block 是 1024 个线程，**一个线程只写 `As[ty][tx]` 自己那一个格子**。
- ❌ **"`A[row*N + t*32 + tx]` 是每隔 32 个取一个"** —— 完全相反，是**连续的 32 个**。
  `t` 固定时 `tx` 走 0..31，下标步长为 **1**。跨 32 跳的是 `t`，不是 `tx`。
- ⚠️ **`handover/2026-11-07-night.md` 第 64 行那句"B tile 大概率要用 `[32][33]`"对他这个写法不成立。**
  那是针对**转置 B 布局** `Bs[tx][k]` 的。他现在用的是自然序 `Bs[ty][tx]`，
  按上面的 bank 算式 `[32][32]` 无冲突。**别让他照着 32×33 去改，会白绕一圈。**
