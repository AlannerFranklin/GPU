## 一、今日内容：Roofline 模型（第 12 周任务②）

### 4070 Ti Super 的两个天花板

```
算力：66 SM × 128 FP32 单元 × 2（FMA 算两次） × 2.61 GHz = 44.1 TFLOPS = 44,100 GFLOPS
带宽：672 GB/s
ridge point = 44.1e12 ÷ 672e9 = 65.6 FLOP/byte
```

判据：`AI < 65.6` → memory-bound；`AI > 65.6` → compute-bound。

### 讲到的核心陷阱

**AI 里的「字节数」必须是真实走 DRAM 的字节数，不是「代码读了几次 × 4」。**

用学员自己 11-10 的实测反证过：
- 教科书算法账：naive 读 2N³ × 4 = 550 GB → AI=0.25 → 带宽天花板仅 168 GFLOPS
- 实测 2413 GFLOPS，是「预测值」的 14 倍
- 原因：L2 + block 行优先调度把 550 GB 吞到约 8.2 GB

**结论已强调：Roofline 的输入必须来自 ncu 实测计数器，不能纸上算。**
这也是为什么 Roofline 和 ncu 必须配套学。

## 二、计算练习（学员做了，结构全对，输错三个数）

题目：N=4096、49.2 ms、DRAM 流量 16 GiB，求 FLOP / GFLOPS / AI / 带宽天花板 / 完成度。

**正确答案：**

```
① FLOP       = 2 × 4096³ = 137,438,953,472  ≈ 1.374e11
② GFLOPS     = 1.374e11 ÷ 0.0492 = 2793 GFLOPS   （与 11-10 实测 tiled 4096 的 2793 吻合）
③ AI         = 1.374e11 ÷ 1.718e10 = 8.0 FLOP/byte   （正好整数，题目按此设计）
④ 带宽天花板  = 672 × 8.0 = 5376 GFLOPS
⑤ 完成度      = 2793 ÷ 5376 = 52%
```

**结论**：AI = 8.0 ≪ 65.6 → memory-bound。已达自身带宽天花板 52%，
但离算力天花板 44,100 GFLOPS 还差 16 倍。

**学员的三个错（都是输入/单位，不是概念）：**

| 错的 | 写的 | 应为 |
|---|---|---|
| FLOP 公式 | `2 × 4096²` | `2 × 4096³` |
| 时间单位 | 除以 49.2（ms）当秒 | 除以 0.0492 |
| 字节单位 | `16 × 1024 × 1024`（=16 MiB） | `16 × 1024³`（=16 GiB） |

**五步的框架他全写对了**（2N³ / FLOP÷时间 / FLOP÷字节 / 672×AI / ④÷②），
只是三个输入值错。判断：**概念理解没问题，是心算 + 单位不落纸的老毛病**。

**已立规矩**：算这类题先单独列一行把单位统一到同一量纲（ms→s、GiB→字节），
禁止在算式里混毫秒和秒、GB 和字节。这与 memory `write-out-the-arithmetic` 同源。

## 三、ncu 命令（讲了，但**未在 GPU 上验证**）

学员机器今晚才能跑。命令已给全：

```bash
# 最简：直接看 Speed Of Light 两个百分比
ncu .\matmul_reg.exe 1024

# 取 Roofline 要的字节数
ncu --metrics dram__bytes.sum,dram__bytes_read.sum,dram__bytes_write.sum .\matmul_reg.exe 1024

# 三个一起要（含 local memory 检查）
ncu --launch-count 1 --metrics dram__bytes.sum,sm__throughput.avg.pct_of_peak_sustained_elapsed,gpu__dram_throughput.avg.pct_of_peak_sustained_elapsed,smsp__sass_inst_executed_op_local_ld.sum .\matmul_reg.exe 1024
```

**已强调的三个坑：**
1. ncu 报的 `Duration` **不能**拿来比性能（会重放 kernel 多次），性能数字永远用 `cudaEvent`
2. 不加 `--launch-count 1` 会采满 4 次启动（main 里是 1 预热 + 3 计时）
3. 报 `ERR_NVGPUCTRPERM` → 用管理员终端
