# 交接：白天 → 晚上 · 2026-11-05

## 今天学了什么

- 对应 ROADMAP **第 11 周 · Shared Memory 与分块**（前半段），并提前碰了第 13 周的归约。
- 核心概念（按讲解顺序）：
  1. `cudaEvent` 计时收尾（热身 + 3 轮取最小）—— 承接昨天，今天补完类型与 API 的坑
  2. **memory coalescing 的量化**：32 字节 sector；连续访问 4 sector / 散开访问 32 sector，8 倍流量
  3. **共享内存层次**：寄存器 / `__shared__` / L1 / L2 / 显存，容量、延迟、可见范围
  4. **`__syncthreads()` 的两个语义**：block 内栅栏；**必须写在所有线程都能到达的位置**（放进 `if` 里会死锁）
  5. **bank conflict**：32 bank × 4 字节，`bank = 下标 % 32`
     - 冲突定义：同 bank **且不同地址**才串行（同 bank 同地址是广播，免费）
     - 判断公式：**冲突路数 = gcd(步长, 32)**
     - 步长与 32 互质 → 无冲突（33、35 可以，34、36 不行）
  6. **padding**：二维按列访问时，行宽要用 33 而不是 32
  7. **二维线程**：`dim3`、`threadIdx.x/.y`、`blockIdx.x/.y`、行优先下标 `row * N + col`
     - `dim3` 不是新东西：`<<<4, 256>>>` 一直是 `<<<dim3(4,1,1), dim3(256,1,1)>>>` 的简写
  8. **二维转置的三个索引全部镜像**：`blockIdx.x/.y`、`threadIdx.x/.y`、`tile[a][b]`
