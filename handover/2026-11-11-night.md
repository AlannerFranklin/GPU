## 对白天设计规格的独立校验（晚上 review）

| 规格项 | 校验 |
|---|---|
| 34 寄存器/线程 × 256 线程 = 8704/block | ✅ 65536 ÷ 8704 = 7.5 → 寄存器上限 7 个 block |
| 1536 ÷ 256 = 6（线程上限） | ✅ Ada SM 上限 1536 线程 |
| min(7,6) = 6 → 1536 线程 = 100% occupancy | ✅ |
| 4×4 先行的理由（8×8 时 80 寄存器 → 3 block → 50%） | ✅ 一次只改一个变量，正确 |
| `Bs` bank 公式：`(k×128 + c) % 32 = c % 32` | ✅ 128 ≡ 0 (mod 32)，k 项被模掉 |
| 列映射 `c = tx + j×32` → warp 内 32 个 bank 铺满 | ✅ 无冲突 |
| 行映射 `row_i = blockIdx.y×32 + ty×4 + i` | ✅ |
| block(32,8) 而非 (16,16) 的理由（warp = tx 0..31、ty 固定，沿用既有 bank 模型） | ✅ 正确，且避免学员已有规则失效 |

**结论：明天的坐标映射专题可以直接用这套规格，无需重推。**
