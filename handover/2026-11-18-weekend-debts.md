## 一、优先级 1：4 种内存序（🔴 最高）

**为什么最急**：门 A / 门 B 面试都问；而且他刚学的 CUDA `__threadfence()`、`atomicAdd`、
decoupled look-back 全部建立在这上面。11-03 自检未过（代码对，讲不出）。

**载体（必须用他自己的代码）**：
- `code/09-thread/` 里的 **SPSC 无锁队列**（环形缓冲 + 两个 `std::atomic<size_t>`）
- `code/09-thread/` 里的 **自旋锁**（`std::atomic<bool>` + `exchange`）

**验收标准**（他必须不看资料说出来的四件事）：

1. `relaxed` / `acquire` / `release` / `seq_cst` 各自保证了什么、没保证什么
2. 他那两个原子变量**为什么必须**用 `acquire` / `release`，换成 `relaxed` 会怎样
   （要求指出具体是哪条指令重排导致的）
3. 为什么 `seq_cst` 是默认值但不能滥用（性能代价在哪）
4. 把它们和 CUDA 侧对上：`__threadfence()` 相当于哪一档

**教法建议**：从「编译器重排 + CPU 重排」两个来源讲起，因为他不接受「规定如此」。
画出生产者写数据 → 写标志 / 消费者读标志 → 读数据这两条路径，指出哪一步可能被换序。

**验收标准**：
